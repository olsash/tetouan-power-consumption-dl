# Tetouan City Power Consumption – Day-Ahead Forecasting with Deep Learning

Deep learning project (CSI_7_DEL coursework) that forecasts the electricity consumption of the
three distribution zones of Tetouan city (Morocco) at 10-minute resolution, one day ahead.

## Dataset
- 52,416 records, every 10 minutes from 1 Jan to 30 Dec 2017
- Features: temperature, humidity, wind speed, general diffuse flows, diffuse flows
- Targets: power consumption of Zone 1, Zone 2 and Zone 3 (KW)

## Approach (CRISP-DM)
| Notebook | Phase |
|----------|-------|
| `notebooks/01_data_understanding.ipynb` | Descriptive statistics, EDA, data quality checks |
| `notebooks/02_data_preparation.ipynb` | Cyclical time features, day-ahead lag features, monthly block split, scaling |
| `notebooks/03_modelling.ipynb` | Naive baseline, Linear Regression, Random Forest, MLP, LSTM, GRU |
| `notebooks/04_evaluation.ipynb` | Model comparison, error analysis, best model selection and reload check |
| `app/` | Flask web app that serves the best model |

## Project structure
```
├── data/                  original dataset (processed/ is generated by notebook 02)
├── notebooks/             01–04 Jupyter notebooks
├── models/                saved models (.keras / .pkl), scalers and best_model.json
├── results/               metrics and predictions
├── figures/               all plots used in the report
├── app/                   Flask deployment (app.py, features.py, templates/)
└── requirements.txt
```

## How to run
```bash
python -m venv venv
venv\Scripts\activate            # Windows  (source venv/bin/activate on Mac/Linux)
pip install -r requirements.txt
```
1. Run notebooks 01 → 04 in order.
2. Start the web app from the project root:
   ```bash
   python app/app.py
   ```
3. Open http://127.0.0.1:5000

## API
| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/forecast_day?date=2017-07-28` | GET | Forecast of all 144 steps of a day for the 3 zones, with MAE/MAPE vs actual |
| `/api/predict` | POST | Single prediction with custom weather, e.g. `{"datetime": "2017-07-28 20:00", "Temperature": 35}` |
| `/api/weather?datetime=2017-07-28 20:00` | GET | Recorded weather for a timestamp |
| `/health` | GET | Health check |
